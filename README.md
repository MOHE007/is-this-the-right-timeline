# 第一章 Demo

《这真的是对的时间线吗？》第一章“靖康前夜”的可运行浏览器 Demo。

## 运行

直接双击 `index.html` 即可打开。若浏览器限制本地文件交互，可在此目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 完整演示路线

1. 打开未读完的问题。
2. 向刘看山提问“这里是哪一年？”。
3. 在驿路场景调查家书、征发文书和湿损路线图；可点击军中同伴获得补充证言。
4. 点击继续，询问“我现在告诉岳飞有用吗？”。
5. 选择“介入时间线”或“保存证言”，观看两个不同结尾。

当前 Demo 使用本地问答库保证离线可通关。后续可以将 `answers` 替换为真实 AI 适配层，而不改变章节流程。
