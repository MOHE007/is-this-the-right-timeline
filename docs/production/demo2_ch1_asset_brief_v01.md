# Demo2 第一章美术与 UI 资产规格 v0.1

## 给梁博森的制作目标

本表是《第一章 南宋意难平》Demo2 的美术与 UI 交接单。两天窗口优先保证一条主路径可运行，先做 P0 资产；P1 用于提升完成度，P2 暂不阻塞演示。

统一画面比例为 **16:9，1920×1080**。整体方向是水墨叙事：灰青、墨黑、旧纸白为主，朱砂只用于诏书封泥、时间线关键节点和玩家确认反馈。画面需要留出对话框与按钮区域，不能把重要人物脸部或线索放在底部 25% 区域。

## 二 角色图

角色图统一使用透明背景 PNG，建议画布 **1024×1536**；人物脚底留 5% 安全边距，视线和脸部不能被裁切。每个角色至少交一张静态立绘；P0 角色可额外交一张情绪变体。

| 优先级 | resource_id | 角色 | 成品规格 | 必要变体 | 视觉要求 |
|---|---|---|---:|---|---|
| P0 | `CHAR_LIUSHAN_WHITE` | 刘看山 | 1024×1024 PNG | 默认、提问、提醒 3 个表情 | 白色剪影/纸面浮现感，边缘带淡墨，不要做成写实动物头像 |
| P0 | `CHAR_CAREGIVER_SILHOUETTE` | 抚养者 | 1024×1536 PNG | 默认、焦急 2 个姿态 | 侧身或背影为主，衣料轮廓清晰，避免具体时代考据细节过多 |
| P0 | `CHAR_OLD_POSTMAN` | 老驿卒 | 1024×1536 PNG | 默认、递信 2 个姿态 | 旧蓑衣、驿灯、手部动作明显；表情克制 |
| P0 | `CHAR_MIGRANT_WITNESS` | 迁徙者 | 1024×1536 PNG | 默认、抱孩子/回望 2 个姿态 | 行囊、湿衣和疲惫姿态传达民生压力 |
| P0 | `CHAR_YUEFEI_BACK` | 岳飞背影 | 1024×1536 PNG | 默认背影即可 | 不做正面英雄海报；披风、军书、等待传令的静止感 |
| P0 | `CHAR_XINQiji_YOUNG` | 年轻辛弃疾 | 1024×1536 PNG | 默认、准备行动 2 个姿态 | 墨线更锋利，少量土红；表现年轻、急切和判断力 |

## 六 声音素材说明

声音不是梁博森的主交付，但可以与美术同步定方向。若暂时没有专职音频，先使用 AI 或免版权素材：

| resource_id | 用途 | 格式 | 最小交付 |
|---|---|---|---|
| `AUD_PAPER_WIND_01` | 纸张、风、远马蹄环境声 | WAV 48kHz/24bit 或 OGG | 10—20 秒无明显循环接缝 |
| `AUD_INK_STAMP_01` | 诏书/时间线确认音 | WAV 或 OGG | 1—2 秒短音效 |
| `AUD_UI_CLICK_INK` | 选择与线索点击 | WAV 或 OGG | 3 个强弱变体 |

## 七 文件命名与交付目录

文件命名统一为：

`demo2_ch1_<类别>_<resource_id>_v版本号.<扩展名>`

示例：

- `demo2_ch1_bg_BG_INK_BABY_HOME_1122_v01.webp`
- `demo2_ch1_char_CHAR_YUEFEI_BACK_v01.png`
- `demo2_ch1_ui_UI_CHOICE_BUTTON_v01.png`
- `demo2_ch1_fx_FX_RED_INK_SPREAD_v01_01.png`

建议交付目录：

```text
assets/ch1_demo2/
├── backgrounds/
├── characters/
├── props/
├── ui/
├── fx/
├── audio/
└── source/
```

源文件放 `source/`，运行时导出文件放对应分类目录。梁博森只需提交自己负责的资源；DSH Desktop 负责压缩、导入、manifest 登记和 fallback 占位图。

## 八 P0 最小交付包

如果时间只够做最小包，优先交这 14 项：

- 6 张关键背景：现代宿舍、婴儿屋、驿站、军镇、1141 诏书、1142 空营。
- 3 个角色：刘看山、老驿卒、岳飞背影。
- 4 张线索道具：家书、军书、路线图、召回诏书。
- 1 套 UI：对话框、选择按钮、线索卡、时间线印章可先合并为一套视觉组件。

梁博森如果先交风格样张，优先顺序是：`BG_INK_BABY_HOME_1122`、`UI_INK_DIALOGUE_FRAME`、`CHAR_LIUSHAN_WHITE`。这三项一旦确定，其他资源可以沿同一规范扩展。

## 九 验收标准

- 资源 ID 与本表完全一致，不能只交“婴儿屋最终版.png”这种无 ID 文件。
- 背景在 1920×1080 下不裁切主要构图，底部对话区可读。
- 角色透明边缘干净，没有白边、黑边或锯齿溢出。
- UI 九宫格四角不变形，按钮至少有默认、悬停、按下三态。
- 朱砂只出现在 1141 诏书、时间线关键节点和选择确认，不扩散到所有界面。
- 所有文字由运行时覆盖，图片内不嵌大段对白或史料正文。
- 每项资源附版本号；修改后保留旧稿，不覆盖已接入稿。
- 首批资源完成后由 DSH Desktop 登记 manifest，并由梁博森与王凯进行视觉确认。
