# Demo2 第一章探索与刘看山能力系统 v0.2

## 目标

把第一章从“对白自动发线索”改成“玩家观察、拾取、提问、验证后才形成有效证据”。玩家可以漏掉道具，也不会卡死；漏掉的动作会关闭特定结局，并给出可理解的后果。

核心循环：观察场景 → 调查对象 → 拾取/记录线索 → 向刘看山提问 → 验证线索 → 解锁行动。

## 三层证据

| 层级 | 玩家动作 | 状态示例 | 作用 |
| --- | --- | --- | --- |
| 物证 | 点击或查看关键道具 | `family_letter`, `military_order`, `route_map`, `civilian_testimony` | 证明事情发生过 |
| 行动资格 | 找到能执行的人或路线 | `recall_recipient_found`, `route_verified` | 允许尝试介入 |
| 刘看山验证 | 提问并得到对应答案 | `shan_answer_recall`, `shan_answer_route` | 把看见变成理解，解锁特殊结局 |

领取道具不会自动等于理解。拿到军书但没有问“谁能执行”，仍不能进入完整介入链。

## 场景调查设计

### 驿站

可调查对象：家书、旧驿牌、老驿卒。

- 拾取家书：获得 `family_letter`。
- 查看旧驿牌：获得 `route_map_fragment`，但不是完整路线图。
- 向老驿卒追问送信路线：获得 `route_map`。
- 不问路线：仍可继续，但后续不能证明消息如何抵达。

### 渡口

可调查对象：迁徙者、湿路线图、船夫名册。

- 保存普通人证言：获得 `civilian_testimony` 和 `testimony_saved`。
- 拾取湿路线图：获得 `route_map_fragment`；没有刘看山帮助时不能验证路线。
- 只带走路线：保留推进权，但关闭真相线的一部分条件。

### 军镇

可调查对象：军书、传令牌、军中同伴。

- 查看军书：获得 `military_order`。
- 拾取传令牌：获得 `recall_recipient_token`。
- 向军中同伴追问执行能力：获得 `recall_recipient_found` 和一次军中信任。
- 没有传令牌或没有问清执行者：不能把预警交给可靠接收者。

## 刘看山能力

刘看山不是无限提示按钮，而是三次关键验证机会。每次提问必须带上下文，回答分为事实、背景、反问三段。

| 能力 | 触发条件 | 消耗 | 解锁 |
| --- | --- | --- | --- |
| 识别年代 | 初到 1122 | 0 | `knows_yuefei_fate` |
| 解析路线 | 持有 `route_map_fragment` 或 `route_map` | 1 次提问 | `route_verified` |
| 解析召回链 | 持有 `military_order` | 1 次提问 | `shan_answer_recall` |
| 判断执行者 | 持有 `recall_recipient_token` | 1 次提问 | `recall_recipient_found` |
| 解释普通人证言 | 持有 `civilian_testimony` | 1 次提问 | `testimony_interpreted` |

没有对应道具时，刘看山只能回答“信息不足”，不会凭空给答案。提问次数照样消耗，鼓励玩家先观察再提问。

## 结局条件

### 时间线一：偏离但未改写

必须同时满足 `military_order`、`route_verified`、`recall_recipient_found`、`shan_answer_recall`，并选择介入、交付预警。缺少任意一项仍可尝试介入，但只进入“消息未能可靠抵达”的普通收束，不能获得 `ending_divergent`。

### 历史轨迹

不要求集齐全部线索。玩家可以选择见证历史，体验“知道结局但没有改变”的结尾。

### 真相线

必须同时满足四类物证、`testimony_interpreted`、至少三类问题都问过、`knowledge_debt <= 2`。拿到道具但没有刘看山解释，真相线仍不开。

## 失败与反馈

失败不重置章节。每次漏拿关键物品都显示因果反馈，例如：“你拿到了军书，但不知道它该交给谁。”“路线图被水浸过，方向存在，距离没有。”“刘看山看见了证言，却无法替你证明它。”玩家可以继续走历史轨迹或普通收束。

## 实施顺序

1. state v02 增加物证、碎片、验证和行动资格字段。
2. content v02 为 s05、s06、s07 增加调查对象和拾取效果。
3. Godot UI 增加调查对象按钮组和已验证标记。
4. s09 介入条件改为三层证据组合。
5. 三种结局补独立反馈文本。
6. smoke test 覆盖漏拿传令牌、拿到但未提问、完整验证。

## 验收指标

- 第一次游玩至少 15 分钟，玩家主动调查 3 个地点。
- 三条结局仍然可达，但不再通过单纯点击默认选项获得。
- 漏掉关键道具时，5 秒内看到明确反馈。
- 刘看山至少有一次“信息不足”的回答，证明他不是全知外挂。
- Demo1 保持不变。
