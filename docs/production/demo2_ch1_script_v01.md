# Demo2 第一章逐幕剧本与对白 v0.1

> 项目：《这真的是对的时间线吗？》  
> 章节：第一章《南宋意难平》  
> 目标时长：20—30 分钟（完整第一章主路径）  
> 本稿用途：交给分镜、美术、UI、运行时实现与历史审校。  
> 时间线硬约束：1122 → 1127 → 1141 → 1142 → 1161。

## 使用约定

- `SCENE_ID` 是运行时和美术交接的稳定编号，后续改字不改编号。
- `SFX` 为音效提示，`BGM` 为音乐提示，`UI` 为界面文字或反馈。
- `LS` 代表刘看山；玩家对白可由玩家自定义姓名替换，本文统一写作“玩家”。
- 方括号内是制作说明，不作为玩家可见文本。
- 所有选择都应记录状态；没有 Game Over，错误选择通过后续反馈表现代价。

## 章节核心弧线

玩家从“我知道结局，所以我能改变结局”的冲动出发，经过二十年调查，最后理解：改变一个人的命运需要消息、信任和执行能力同时成立。第一章的完成感来自做出一次有代价的行动，并在岳飞段落后决定离开或继续追问。

## SCENE 00｜现代宿舍：读到一半的问题

**时间**：现代，夜。  
**地点**：宿舍书桌。  
**目标**：建立知乎入口、玩家动机和本章核心问题。  
**预计时长**：2—3 分钟。

[画面：电脑屏幕和手机光交叠，水墨纹理从屏幕边缘渗出。知乎文章标题可暂定《岳飞如果没有被召回，南宋会怎样？》。阅读进度停在 72%。]

**UI 文案**

> 阅读进度 72%  
> 相关问题：如果你知道一个人二十年后的结局，你会回去改变它吗？

**玩家（内心）**：我只是想看完一篇文章。为什么每次读到结局，都会觉得还差一步？

**LS（文字气泡，第一次出现）**：你想改的是结局，还是那个已经来不及回答的问题？

**玩家**：你是谁？

**LS**：刘看山。知乎大千世界的看门狗，偶尔替人把问题看完。

**玩家**：如果我知道他二十年后会死，我能回去救他吗？

**LS**：你可以回去。能不能救下他，要看你能带回什么、说服谁，以及谁愿意替你把话送到终点。

[玩家点击按钮。]

**选择 A｜回去改变他**  
**选择 B｜先把文章读完**

- A：进入 SCENE 01，`action_intent += 1`。
- B：屏幕自动翻到空白页，仍进入 SCENE 01，`witness_intent += 1`。

**LS（转场）**：答案不会等你准备好。先记住年份。

## SCENE 01｜两岁的来客：1122 年

**时间**：1122 年，北宋末年。  
**地点**：乡村民居，夜转清晨。  
**目标**：明确玩家以两岁婴儿身份穿越；建立感官式交互和“二十年”倒计时。  
**预计时长**：4—5 分钟。

[画面：低机位看屋梁，衣料、木盆、铜钱依次进入前景。玩家不能自由行走，只能点击可听见或可触摸的物件。]

### 交互 1：屋梁与大人声音

**抚养者**：别哭，别哭。外头又在传粮价，咱们把米袋收好。

**邻人（屋外）**：北边的路不太平，商队都改道了。

**玩家（内心）**：我听得懂每一个字，却说不出一句完整的话。

**LS**：你现在只有两岁。知道答案，不等于有能力说服别人。

### 交互 2：旧铜钱

[玩家触碰铜钱，出现极短闪回：陌生城市的键盘声、文章标题、岳飞的名字。]

**玩家**：这里是哪一年？

**LS**：1122 年。北宋还没有结束，南宋也还没有开始。

**玩家**：岳飞呢？

**LS**：他还活着，也还没有成为你记忆里的那个人。

**玩家**：他什么时候会死？

**LS**：史料记载，他在 1142 年离世。从你来到这里算起，大约二十年。

**玩家**：二十年……我有二十年可以改变它。

**LS**：你有二十年可以长大、查证、获得信任。至于改变什么，先不要急着替历史写结论。

### 交互 3：远方马蹄

[SFX：远马蹄，停顿，屋内呼吸声。]

**抚养者**：睡吧。明天还要赶路。

**玩家（内心）**：我把“1142”藏进心里，像藏起一根没人看得见的针。

**LS（低声）**：倒计时开始。`year = 1122`，`deadline = 1142`。

[转场：水墨长卷快速向右展开，婴儿手指逐渐变成少年手掌。]

## SCENE 02｜靖康之后：长大与三处调查

**时间**：1127 年后，建议表现为 1130—1140 年的成长蒙太奇。  
**地点**：驿站、渡口、临时军镇。  
**目标**：让玩家通过四类线索理解“命令—路线—民意—执行者”，完成至少三次有效提问和一次信任变化。  
**预计时长**：8—10 分钟。

**LS（旁白）**：1127 年，靖康之变后，北宋灭亡，南宋建立。你已经不再只是被抱在怀里的孩子。

**玩家（内心）**：我记得一个年份，却不记得自己该站在哪一边。

[玩家可按任意顺序调查三处场景；运行时需在集齐四条线索后开放 SCENE 03。]

### 02A｜驿站：老驿卒与家书

**角色**：老驿卒。  
**线索**：`clue_family_letter`，家书；`clue_route_map`，旧驿路图。

**老驿卒**：这封信压了三天，不是路断，是没人敢在夜里点灯。

**玩家**：信里写了什么？

**老驿卒**：家里人只问一句，粮还够不够。可每一笔都像在问，谁还活着。

**玩家**：如果是军令，三天会怎样？

**老驿卒**：军令有军令的路，家书有家书的路。可路上都是同一场风雪。

[玩家查看路线图。]

**UI｜获得线索**

> 家书：消息可能被延误，不一定是有人故意拦截。  
> 旧驿路图：送达需要经过驿站、渡口和军镇三类节点。

**玩家向 LS 提问 1｜事实型**：消息为什么会晚？

**LS**：事实：驿路依赖人、马和渡口，任何一个节点停摆都会延误。背景：战争让军令和家书挤在同一条路上。反问：你要查的是哪一个节点？

**老驿卒（信任变化）**：你问路，不先问功名。好，这张图借你看一晚。`trust_common += 1`。

### 02B｜渡口：迁徙者与征发文书

**角色**：迁徙者。  
**线索**：`clue_requisition`，征发文书；`clue_testimony_migrant`，普通人证言。

**迁徙者**：我们从北边来，走到哪儿就被问到哪儿：粮、船、壮丁，什么都要。

**玩家**：这张文书是谁发的？

**迁徙者**：印看不清。负责收粮的人说是上头的命令，负责押船的人说自己只听军镇的。

**玩家**：你相信他们吗？

**迁徙者**：我只相信能让我孩子今晚睡下的人。

[玩家查看文书背面的转运印。]

**UI｜获得线索**

> 征发文书：命令的来源与执行者可能不是同一批人。  
> 迁徙者证言：普通人承担消息流动的成本。

**玩家向 LS 提问 2｜背景型**：一张文书为什么不能让所有人都照做？

**LS**：事实：文书需要被确认、解释并交给有权限的人执行。背景：战争中的命令层层转递，印章不等于信任，信任也不等于兵力。反问：你要找到的是发令者，还是能执行的人？

**迁徙者**：如果你真要送什么消息，先告诉我它会让谁承担代价。`trust_common += 1`。

### 02C｜军镇：军中同伴与军书

**角色**：军中同伴。  
**线索**：`clue_military_dispatch`，军书；`clue_yuefei_name`，岳飞名号。

**军中同伴**：岳家军在前线守住过几次缺口。可军镇里谈得最多的，不是胜仗，是粮道能不能撑住。

**玩家**：岳飞会听陌生人的话吗？

**军中同伴**：他会听证据，也会听士卒和百姓怎么说。你要是只带一句“我知道未来”，没人会替你开门。

[玩家查看军书，军书只露出“调回”“待命”等字样，不出现完整召回诏书。]

**UI｜获得线索**

> 军书：岳飞的军务受制于更大的调度体系；“调回”是命令链中的动作，不是单独事件。

**玩家向 LS 提问 3｜反问型**：如果我只能改一件事，应该改哪一件？

**LS**：事实：你目前掌握了来源、路线、民间代价和军中执行四类碎片。背景：改变召回需要消息可靠抵达，也需要接收者愿意相信并有能力行动。反问：你想先让谁知道，还是先让谁能够行动？

**玩家（内心）**：我终于明白，二十年不是一把钥匙，是一条必须接通的链。

[集齐 `clue_family_letter`、`clue_route_map`、`clue_requisition`、`clue_military_dispatch` 后：]

**LS**：1141 年快到了。你可以把证据交给一个人，但不能同时替所有人承担后果。

**UI**：`evidence_complete = true`；开放 SCENE 03。

## SCENE 03｜1141 年的诏书：信息链行动

**时间**：1141 年。  
**地点**：军镇外的驿路与临时文书房。  
**目标**：完成“来源 → 路线 → 接收者 → 执行能力”的信息链，决定是否进入时间线一。  
**预计时长**：5—7 分钟。

[画面：朱砂只出现在诏书封泥和时间轴 1141 标记。玩家可把四条线索拖到信息链四个槽位。]

**UI｜任务**

> 让预警可靠抵达：
> 1. 确认来源  2. 确认路线  3. 确认接收者  4. 确认接收者的执行能力

**玩家**：来源是朝廷，路线走驿站，接收者是岳飞。这样就够了吗？

**LS**：还差最后一问：谁能在诏书抵达后做出不被立刻瓦解的决定？

### 行动选择

**选择 A｜把完整预警交给军中同伴，请他转交岳飞**

**军中同伴**：我能把话带进军镇，但我不能保证每一道门都听我的。

**玩家**：那就把家书和军书一起带上。让他们看见，命令会落到谁身上。

**军中同伴**：你不是在求一个人逃走，你是在求他们先把后果说清楚。`trust_military += 1`。

- 条件：四条线索齐全且 `trust_common >= 1`。
- 效果：`warning_reliable = true`，`execution_path = military_companion`。

**选择 B｜先把预警交给迁徙者，让消息随民间队伍扩散**

**迁徙者**：消息会传得更远，也会传得更乱。你确定要把他们卷进来？

**玩家**：至少有人会知道，诏书不是天上掉下来的。

**迁徙者**：那就写清楚来源。别让我们替你背一个没有名字的命令。

- 效果：`warning_public = true`，`trust_common += 1`，但 `warning_reliable = false`。

**选择 C｜把唯一一份证据藏起来，等更确定的时机**

**LS**：等待也是行动。只是时间不会因此停下来。

- 效果：`warning_reliable = false`，`knowledge_debt += 1`。

### 1141 选择确认

**UI 确认文案**：

> 你要把什么交给历史？  
> [交出预警] [保留证据]

**玩家（内心）**：我曾以为改变只需要勇气。现在我知道，还需要一个愿意承担的人。

**LS**：记录完成。历史会从你没有覆盖的空白处继续。

## SCENE 04｜1142 年：空营与未寄出的信

**时间**：1142 年。  
**地点**：军镇旧营、封存文书房。  
**目标**：以留白表现历史结点，不直接表现残酷场面；展示局部影响和代价。  
**预计时长**：3—4 分钟。

[画面：空营、未收的马槽、封存的信匣。远处传来钟声。岳飞本人只以远处背影或军书落款出现。]

### 分支 A：时间线一——岳飞未被召回

**触发条件**：`warning_reliable = true` 且执行链完整。

**军中同伴**：诏书到了，但人没有立刻走。有人终于肯把调度和粮道摊在桌上谈。

**玩家**：所以我改变了？

**LS**：你改变了一个节点。岳飞暂时未被召回，或召回被延迟；军队获得了时间，朝廷也获得了新的压力。

**军中同伴**：前线多留一天，粮就少一分。你救下的不是一场胜利，是一段还没结算的账。

**玩家（内心）**：空营没有变成凯旋门。只是那匹等人的马，还没有被牵走。

**UI｜时间线一**

> 1141：预警可靠抵达  
> 岳飞：未被召回／召回延迟  
> 新问题：军政压力由谁承担？

### 分支 B：时间线二——你没有做到，历史轨迹继续

**触发条件**：`warning_reliable = false`。

**老驿卒**：信还是晚了三天。三天足够让一条路变成另一条路。

**玩家**：我明明已经知道结局。

**LS**：知道结局，只能让你更早感到疼。它不能替你补上来源、路线、信任和执行能力的缺口。

**玩家**：岳飞呢？

**LS**：1142 年，历史轨迹继续。你不必观看残酷场面，也应当记住它留下的空白。

[玩家打开信匣，看到一封没有寄出的家书。]

**抚养者（家书旁白）**：若你还在路上，记得回来。若回不来，也别让人把你的名字说成一句口号。

**UI｜时间线二**

> 1142：历史轨迹继续  
> 留存：家书、军书、普通人证言  
> 未完成：消息为什么没能抵达？

### 共同的见证结算

**LS**：无论哪条时间线，你都留下了三样东西：帮助过的人、被写下的证言、一个没有被回答完的问题。

**UI 变量结算**

- `witness_intent`：见证倾向
- `action_intent`：介入倾向
- `knowledge_debt`：改变带来的新风险
- `chapter1_yuefei_state`：`delayed_recall` 或 `historical_trajectory`

## SCENE 06｜1161 年辛弃疾入口：新的第一步

**时间**：1161 年。  
**地点**：江北边地的夜色、抗金队伍临时驻地。

**玩家**：你要我做什么？

**UI｜第一章完成**

## 结尾语气与分支验收

### 时间线一（岳飞未被召回）

- 玩家看到的是“暂时偏离、压力上升”，不能显示为爽文胜利。
- 必须明确至少一个代价：粮道压力、军政冲突、信任重新分配三者之一。
- “直接进入下一章”和“继续游戏”均可点击。

### 时间线二（历史轨迹继续）

- 不将结果标记为玩家操作失败；应表现为消息链缺口与时代结构。
- 以空营、封存信、未寄家书表达 1142 年结点。
