# 第一章垂直切片冻结表

## 目标

在两天窗口内做出 Demo2 第一章一条 20 至 30 分钟的完整主路径。主路径必须从现代知乎文章入口走到岳飞段落结点，并让玩家明确体验两条时间线和“离开 / 继续”的选择。

## 固定主路径

1. 现代宿舍：读到一半的知乎文章提出“如果你知道一个人二十年后的结局，你会回去改变它吗”。
2. 1122 年：玩家穿越成两岁婴儿，通过声音、物件和大人谈话认识时代。
3. 刘看山回答：玩家得知岳飞约二十年后于 1142 年离世。
4. 1127 年后：玩家长大，在驿站、渡口或军镇调查家书、军书、路线图和普通人证言。
5. 1141 年：围绕召回诏书完成“来源 → 路线 → 接收者 → 执行能力”的信息链。
6. 时间线分叉：
   - 时间线一：预警可靠抵达，岳飞未被召回或召回被延迟；展示新的军政压力。
   - 时间线二：玩家没有做到，历史轨迹继续；展示玩家留下的证言与未完成的问题。
7. 1142 年：以空营、封存的信和未寄出的家书表现结点，不直接表现残酷场面。
8. 结尾选择：直接进入下一章，或继续游戏进入 1161 年辛弃疾入口。
9. 辛弃疾入口：完成一次相遇、一次具体帮助和一个新问题，不展开完整第二章。

## 必须保留

| 项目 | 验收标准 |
|---|---|
| 穿越设定 | 玩家明确从现代进入 1122 年两岁婴儿视角 |
| 二十年倒计时 | 刘看山明确说出岳飞 1142 年离世，玩家理解“二十年” |
| 调查与提问 | 至少 4 条线索、至少 3 次有效提问、至少 1 次普通人信任变化 |
| 1141 信息链 | 玩家能理解召回不是单一物件谜题，而是消息流与执行能力问题 |
| 两条时间线 | 结果有可见差异，且时间线一不是无代价爽结局 |
| 双选项 | “直接进入下一章”和“继续游戏”都可点击并记录状态 |
| 辛弃疾入口 | 继续游戏后看到 1161 年、辛弃疾和一个新的行动问题 |
| Demo1 保留 | `/Users/mac/Downloads/比赛用/第一章Demo/` 内容不被覆盖 |

## 可以压缩

- 自由探索面积压缩为 3 个场景：婴儿屋、驿站/渡口、军镇/诏书场。
- 普通人角色压缩为 3 位：抚养者、老驿卒、迁徙者。
- 岳飞本人只保留一次短接触，以背影、军书和等待传令表现。
- 辛弃疾只做入口，不制作完整战斗或大地图。
- 联网知乎搜索只作为回答档增强，离线本地问答必须可完成全流程。
