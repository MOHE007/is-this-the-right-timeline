# Demo2 第一章探索剧本 v0.2

## 使用说明

本稿是 v01 剧本的探索改版增量。s01-s04、s08-s14 保留原稿；本稿重写 s05-s07，并规定刘看山的“信息不足”反馈。

## s05 驿站：家书不是军令

**进入**：老驿卒把一封没有官印的家书压在灯下：“它走过三双手，最后才到我这里。”

**调查对象**：

1. 查看家书 → `find_family_letter`。玩家看到缺页、折痕和收信地。
2. 查看旧驿牌 → `find_route_map_fragment`。玩家只得到方向，不知道距离和接收者。
3. 询问老驿卒送信路线 → `find_route_map`、`ask_context`。完整路线出现。

**刘看山**：有路线碎片或完整路线时，可问“这条路为什么能走通？”；没有路线时回答：“我只能看见你手里的纸，不能替你补出丢失的路。”

**离开反馈**：若未取得家书，显示“你记住了驿站的位置，却没有留下这封信。”

## s06 渡口：证言会不会沉下去

**进入**：迁徙者说：“我们不是地图上的箭头。下一道命令会把我们赶到哪里？”

**调查对象**：

1. 保存迁徙者证言 → `hear_civilian_testimony`。
2. 拾取湿路线图 → `find_route_map_fragment`。
3. 查看船夫名册 → `record_ferry_register`，获得接触路线的旁证，但不替代完整路线。

**刘看山**：持有证言时可问“这句话能证明什么？”；回答后 → `testimony_interpreted`。没有证言时回答：“我没有原话，只有你的转述，不能替你作证。”

**取舍**：保存证言会增加 `trust_public`，但玩家错过一次追查船夫名册的机会；只记录路线保留推进权，但关闭真相线的一部分。

## s07 军镇：谁有资格执行

**进入**：军中同伴把军书翻到缺页：“命令写下来只是开始，真正的问题是谁能收到。”

**调查对象**：

1. 查看军书 → `find_military_order`。
2. 拾取传令牌 → `find_recall_recipient_token`。
3. 询问军中同伴执行能力 → `find_recall_recipient`、`gain_military_trust`、`ask_counterfactual`。

**刘看山**：持有军书时可问“召回链如何成立？” → `shan_answer_recall`；持有传令牌时可问“谁能执行？” → `recall_recipient_found`。缺少对应道具时均返回 `insufficient`。

**离开反馈**：若没有传令牌，显示“你知道命令存在，却没有找到能把它送到正确的人。”

## 1141 介入前提示

刘看山：“你现在可以把预警交出去，但先看清楚自己拥有的是物证、路线，还是一个真正能行动的人。缺一项，历史不会替你补齐。”

## v0.2.1 修订锁定

- 1140：先出现班师诏与“十二道金牌”的消息链；1141：兵权收束、构陷与和议形成介入门槛，避免把两年压成一句提示。
- 空营旁补台词：“营还在，人不在了。” 岳飞的死亡地点明确为临安大理寺。
- 1141 介入提示统一为：“你需要物证、路线、看得懂召回链、以及一个能行动的人。”
- s12 出口回显玩家在 1141 的具体选择；s14 补年龄台词：玩家 41 岁，辛弃疾 21 岁。
- 调查离开时只对未拾取对象触发 `remember_missed_clue_if_absent`；已取得家书/证言/传令牌不会被误记为遗漏。
- s06 的“保存证言”和“查看船夫名册”属于 `ferry_action` 互斥组，选择一项后另一项显示已放弃。
