## 下一步优先级

### P0 今天必须推进

1. 梁博森确认 3 个风格锚点：`BG_INK_BABY_HOME_1122`、`UI_INK_DIALOGUE_FRAME`、`CHAR_LIUSHAN_WHITE`。
2. Codex 从剧本抽出独立的分镜表、角色卡、线索卡，避免美术继续从长剧本猜画面。
3. DSH Desktop 建立 Demo2 独立 Godot 工程，先用占位图加载 14 个场景和 JSON，确保流程能跑通。
4. Marvis 审校剧本 v0.1，优先检查 1141 召回因果和两条时间线的差异。

### P1 第一条可运行路径

1. 用占位美术完成：现代入口 → 1122 → 1127 调查 → 1141 信息链 → 时间线二 → 1142 → 继续 → 1161。
2. 再补时间线一“岳飞未被召回/召回延迟”，并显示至少一个代价。
3. 接入本地刘看山问答，确保联网失败仍可完整通关。
4. 加入保存点、调试开关和窄窗口检查。

### P2 发布准备

1. 将梁博森最终资产登记到 manifest。
2. 运行 Godot Web 导出并用静态服务器验证。
3. 做一次 3 分钟演示路径和一次完整试玩路径。
4. 由王凯确认是否提交 OAuth 版本；未确认前保持关闭。

- 1141 信息链确实检查来源、路线、接收者和执行能力。
- 刘看山本地问答可用，联网失败不阻塞。
- Demo1 目录仍未被修改。
