# 第一章叙事增强提案 v0.1

这份提案把盐选故事常见的阅读节奏转译为原创游戏结构：开场快速提出高概念问题，调查中连续升级，每获得一条线索就暴露一个新矛盾，在 1141 年制造一次证据反转，最后以代价和留白收束。它不复制任何盐选付费正文、标题、角色或段落。

## 不新增 scene_id 的增补点

| scene_id | 调查动作 | 新信息 | 反馈 |
|---|---|---|---|
| `s05_station` | 查封泥、问送信路线、翻家书折痕 | 消息会慢，延误不必然等于阴谋 | 老驿卒给出一晚借阅权限 |
| `s06_ferry` | 核对转运印、保存迁徙者原话、询问水位 | 命令和执行者分离，普通人承担流动成本 | `trust_public` 与证言状态变化 |
| `s07_military_town` | 比对军书措辞、问权限、查看缺页 | 接收者是否有能力行动比“知道未来”更关键 | `trust_military` 变化 |
| `s08_yuefei_countdown` | 事实 / 背景 / 反事实三问 | 知道终点不等于知道责任链 | `inquiry_types` 补齐 |
| `s09_recall_chain` | 重排来源→路线→接收者→执行者 | 证据链出现断点 | 开放介入或保存证言 |
| `s10_intervention` | 选择谁承担代价 | 干预会带来新军政压力 | `knowledge_debt` 变化 |
| `s11_outcome_router` | 阅读三张结果卡 | 三种结局各有代价 | 路由到 `s12_leave_or_continue` |

## 节奏卡

1. **钩子（s01）**：阅读进度停在 72%，玩家先看到问题再看到答案。
2. **能力落差（s02-s04）**：两岁婴儿知道 1142，却没有说服任何人的能力。
3. **连续升级（s05-s07）**：家书、路线图、征发文书、军书逐步从“物件”变成“消息链”。
4. **证据反转（s08-s09）**：召回来源可以核验，但来源可信不代表执行能力存在。
5. **道德成本（s10）**：玩家选择的是谁承担风险，而不是一个无代价的好结局。
6. **余波（s11-s14）**：空营、封存信和 1161 年的新问题把第一章变成下一章的入口。

## 三张结局卡

- `ending_canonical`：证据不足或选择保存证言，历史轨迹继续；留下消息链断点，`knowledge_debt` 较低。
- `ending_divergent`：四类线索齐全、预警可靠抵达且军中信任成立；岳飞未被召回或召回延迟，但新增粮道和命令冲突，绝不表现为无代价爽结局。
- `ending_truth`：事实、背景、反事实三类提问齐全，玩家保存证言并认识到后世叙述不等于现场真相；不能保证改变结果，却把普通人的声音带出时间线。

## 审校边界

史实细节以公开可靠资料和团队审校为准；盐选故事只用于研究叙事机制。联网检索失败时，不在剧本中伪造“已核实”的知乎来源。
