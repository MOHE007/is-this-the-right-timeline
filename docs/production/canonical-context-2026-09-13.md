## 项目定位

项目名：《这真的是对的时间线？》

核心体验：玩家从一篇没有读完的知乎文章进入“知乎大千世界”，在刘看山引导下穿越历史，通过提问、调查、选择和承担后果理解“知道结局之后，我们真的能改变什么”。

目标发布形态：HTML5 网页版；桌面构建用于内部测试和演示兜底。

目标引擎：Godot 4.x + GDScript + Web 导出。内容管线是 Markdown 供人审阅，JSON 供运行时消费。
